SCAN FAITH

NEXT-GEN DIETARY SCANNER

01 // THE OBJECTIVE

To build a privacy-first, intelligent analysis tool that automates dietary verification. The goal was to interface with the Open Food Facts API to flag specific non-halal additives (like E-codes, Gelatin, and Ethanol) in real-time directly within the browser.

02 // THE TECH STACK

PYTHON FLASKOPEN FOOD FACTS APIHTML5-QRCODEJAVASCRIPT

03 // CORE ARCHITECTURE

  • Live Barcode Parsing: Utilized HTML5-QRCode to stream and decode camera feeds natively within the mobile browser without requiring a native app installation.
  • Heuristic Filtering: Cross-referenced API return payloads against a hardcoded JSON dictionary of prohibited E-codes and text-based ingredient markers.
  • Secure Tunneling: Deployed ngrok during development to bypass strict HTTPS requirements for browser-based camera access on iOS and Android devices.
